# เอกสารรายงานการวิจัยและพัฒนาสิ่งประดิษฐ์ของคนรุ่นใหม่ (แบบ ว-สอศ-3)
## โครงการ: "น้องเพชร AI Smart Guide"
**วิทยาลัยอาชีวศึกษาเพชรบุรี สำนักงานคณะกรรมการการอาชีวศึกษา (สอศ.)**

---

### รายการเอกสารในโฟลเดอร์นี้

1. **[บทที่ 3: วิธีการดำเนินงานวิจัย](บทที่_3_วิธีการดำเนินงานวิจัย.md)**
   - 3.1 การวิเคราะห์ความต้องการของระบบ (ที่มา, ความเป็นไปได้, ความต้องการผู้ใช้, เครื่องมือที่ใช้)
   - 3.2 การออกแบบด้านฮาร์ดแวร์ (โครงสร้างหุ่นฟิวเจอร์บอร์ด, ผังวงจร ESP32 กับ Ultrasonic HC-SR04, ไฟ LED, การเชื่อมโยงสายสัญญาณ และวงจรแบ่งแรงดัน 5V -> 3.3V)
   - 3.3 การออกแบบด้านซอฟต์แวร์ (Flowchart การทำงานของโปรแกรมหลัก, สถาปัตยกรรม Hybrid AI Architecture)
   - 3.4 กระบวนการพัฒนาปัญญาประดิษฐ์ 3 ขั้นตอน (การเตรียม Dataset ภาษาไทย 1,200 ตัวอย่าง, การฝึกสอนโมเดล TF-IDF + Linear SVM, การประเมินผลด้วย Confusion Matrix และเกณฑ์วัดผล Accuracy 100% / F1-Score 1.0)
   - 3.5 ระเบียบวิธีการทดสอบประสิทธิภาพของระบบ (การทดสอบความแม่นยำ, ระยะตรวจจับ และเวลาในการตอบสนอง)
