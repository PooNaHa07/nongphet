# เสียงต้นแบบน้องเพชร (OmniVoice)

โฟลเดอร์นี้เก็บเสียงต้นแบบที่เซิร์ฟเวอร์เสียง (`tools/voice_server.py`) ใช้โคลนเป็นเสียงน้องเพชร

| ไฟล์ | คืออะไร |
|---|---|
| `nongphet_ref.wav` หรือ `nongphet_ref.mp3` | เสียงต้นแบบ 3–10 วินาที |
| `nongphet_ref.txt` | ข้อความที่อ่านในไฟล์เสียง ต้องตรงทุกคำ |
| `nongphet_voice.pt` | ไฟล์เสียงที่โมเดลเตรียมไว้ (สร้างอัตโนมัติครั้งแรกที่รันเซิร์ฟเวอร์) |

ไฟล์เสียงเป็นข้อมูลส่วนบุคคลของเจ้าของเสียง **ไม่ถูก commit ขึ้น git** (อยู่ใน `.gitignore`) ให้เก็บสำรองเอง

## ใครเป็นเสียงต้นแบบ
- นักศึกษาหญิงที่**ยินยอมเป็นลายลักษณ์อักษร** ให้ใช้เสียงเป็นเสียงมาสคอตในงานประกวด
- น้ำเสียงสดใส ยิ้มขณะพูด พูดชัด ไม่เร็ว ตรงบุคลิกน้องเพชร
- **ห้ามใช้เสียงจาก TTS อื่น (เช่น เปรมวดีของ Microsoft) เสียงนักพากย์ หรือคลิปจากอินเทอร์เน็ต**
- อัดผู้สมัคร 2–3 คน แล้วฟังเทียบผลจากโมเดลก่อนเลือก

## วิธีอัด
1. ห้องเงียบ ไม่มีเสียงแอร์ เสียงสะท้อนน้อย (ห้องที่มีผ้าม่าน/โซฟาดีกว่าห้องโล่ง)
2. ไมค์ห่างปากประมาณหนึ่งฝ่ามือ ใช้มือถือรุ่นใหม่อัดได้
3. อ่านบทด้านล่าง 1 รอบ ความยาว 5–10 วินาที ไม่มีเสียงหายใจแรงหรือเสียงคลิกต้นท้าย
4. บันทึกเป็น WAV (mono) ตั้งชื่อ `nongphet_ref.wav`
5. พิมพ์ข้อความที่อ่าน**ตรงตามเสียงจริงทุกคำ**ลง `nongphet_ref.txt` (UTF-8)

บทสำหรับอ่าน:

> สวัสดีค่ะ น้องเพชรยินดีต้อนรับสู่วิทยาลัยอาชีวศึกษาเพชรบุรีนะคะ วันนี้อยากรู้เรื่องอะไร ถามน้องเพชรได้เลยค่ะ

## เปลี่ยนเสียงต้นแบบ
1. แทนที่ `nongphet_ref.wav` และ `nongphet_ref.txt` แล้วลบ `nongphet_voice.pt`
2. เปลี่ยน `VOICE_ID` ใน `.env` ของ Pi (เช่น `nongphet-omni-v2`) ไม่งั้นจะเล่นไฟล์เสียงของเสียงเก่าที่อัดไว้
3. รัน `python prebake_tts.py` เพื่ออัดเสียงใหม่ทั้งหมด
